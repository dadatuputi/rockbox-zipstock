ZipStock: a Rockbox theme for the Sansa Clip Zip in the style of its
original firmware
=====================================================================

ZipStock makes Rockbox on the Clip Zip look like the player's original
firmware, and adds menus for audiobooks by author, by series and by title.
It uses the tags your books already have.

You need a Sansa Clip Zip already running Rockbox. It was tested against a
Rockbox development build from October 2026.

Install
1. Connect the player to your computer. Copy the .rockbox folder from this
   zip onto the player's internal drive, not the microSD card. Merge it with
   the .rockbox folder that is already there. None of Rockbox's own files
   are replaced.
   macOS and Linux hide folders whose names start with a dot. To show them,
   press Cmd+Shift+. in Finder, or Ctrl+H in most Linux file managers.
2. Eject the player. On the player, go to Settings > Theme Settings >
   Browse Theme Files > zipstock.
3. Go to Settings > General Settings > Manage Settings > Browse .cfg Files >
   zipstock-setup. This sets the main menu order, autoresume, bookmarks and
   faster scrolling. The main menu pictures come from Rockbox's icons, so
   leave Settings > Theme Settings > Show Icons on.
4. Build the database once: Settings > General Settings > Database >
   Initialize Now. It scans in the background while you use the player;
   give it a few minutes for a large library. Then turn the player off and
   on. At start-up Rockbox asks whether to finish the database: press
   Select, or wait 5 seconds. Any other button says no. After that the
   database updates itself at start-up when files change.
5. Go to library > Audiobooks.

What it does
- Main menu: one large picture per page with a lower-case name. Up and Down
  move between pages, and Select opens one. The pages are playing, library,
  resume, folders, radio and settings.
- Lists: five rows in a rounded font, with a blue selection bar. Long lines
  scroll sooner and faster than Rockbox's default.
- Now Playing: the cover, author, book, series (or part number), chapter
  title, a progress bar, and time gone and left. The volume shows while you
  change it.
- Library > Audiobooks has three lists:
    Authors     each author, then their books. A book in a series starts
                with its series and number, so a series lists in order:
                "Harry Potter #5: Harry Potter and the Order of the
                Phoenix".
    Series      each series and number, then the book. Two editions of the
                same book both appear.
    All Books   every book, by name.
  The usual music menus follow, with the books left out.
- Each book resumes where you left it, however you open it.
- The back button goes back one screen, and holding it goes to the main
  menu. Left still goes back as well. Only that button changes.

How books are found
- A file is an audiobook when it is inside a folder named AUDIOBOOKS, on the
  player or the card, or when its name ends in .m4b.
- Books are listed by their album tag, which holds the book title in most
  audiobook files. A book with no album tag is listed by its file name.
- A book split into several files gets one line per file: "Book",
  "Book, part 2". Picking a book queues the rest of the list, so the next
  one starts when it ends.
- Series come from the grouping tag, written as "Series #N". Several series
  can be separated by "; ", as in "Harry Potter #5; Wizarding World #5".
  Audiobookshelf's Embed Metadata tool writes this format, and any tag
  editor can set it. Only groupings that contain a "#" count as series.
  Books without a series still appear under their author and in All Books.
- Rockbox adds [All tracks] and [Random] to the top of the Authors and
  Series lists. A theme can't remove them.

Covers
Rockbox shows covers embedded in the file as JPEG, or a cover.jpg or
folder.jpg file next to the book. It can't show PNG or progressive JPEG
covers, so those books get a plain book picture instead.

Chapters
Rockbox doesn't read the chapters inside .m4b files. If a book has a cue
sheet with the same name next to it (Book.cue beside Book.m4b), Next and
Previous skip between its chapters.

If the player says "key remap failed"
Your Rockbox build numbers its button actions differently from the one this
was made for. Delete /.rockbox/keyremap.kmf. Everything else keeps working,
and the back button behaves as Rockbox's default.

To undo
- Theme: Settings > Theme Settings > Browse Theme Files > cabbiev2.
- Audiobook menus: delete /.rockbox/tagnavi_user.config.
- Back button: delete /.rockbox/keyremap.kmf and restart the player.
